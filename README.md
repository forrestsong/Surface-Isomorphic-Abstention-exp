# SIA — Surface-Isomorphic Abstention

Source and code for

> **SIA: Surface-Isomorphic Abstention — Learning to Say "I Don't Know"**
> Sen Song, Independent Researcher, Guangzhou, China

## What the paper claims

Large language models hallucinate most readily where they have no evidence: no
ground truth exists to shape a reward, and no retrievable evidence exists in
context. The paper treats abstention there as a class to be learned rather than
a question of correctness, and asks what makes its training data work.

It gives a falsifiable criterion. **Counter-example completeness** is stated
relative to the surface features that training and evaluation *share*: no rule
expressible in those features may fit the training set better than chance. The
criterion comes with a test that uses only the training set and no ground
truth, `surf_CV`, the cross-validated accuracy of a surface-only discriminator.

It then presents **SIA** (Surface-Isomorphic Abstention), a four-step recipe
that teaches answers and abstentions with ordinary supervised fine-tuning — no
reward model, no RL loop, 94 s per arm — and evaluates it on a controlled
construction that *passes* the test: `surf_CV` lands exactly on the majority
baseline, so no usable surface rule exists. On that construction SIA drives the
fabrication rate on unseen entities and unseen phrasings from 0.933 to **0.000**
and abstention from 0.000 to **1.000**, with verifiable capability unchanged.

The criterion is shown to have teeth. Three conditions originally read off
practice — that the two slices share surface structure, that abstention and
answer examples share templates, and that there be at least three unknown
entities — are its three axes, and breaking any one of them collapses the
effect to exactly 0.000.

## Repository layout

```
SIA_abstention.tex      the paper

```

## Building the paper

```bash
pdflatex SIA_abstention.tex   # twice
```

The source is pure ASCII and self-contained apart from `figures/`. It builds
with pdfLaTeX or XeLaTeX on a stock TeX Live, and needs no special fonts.

## Running the experiments

See [`exp/README.md`](exp/README.md) for the full description, the model
requirement, and the two reproducibility caveats worth knowing before you try.

Requires Python 3.11, PyTorch 2.13.0+cu130, a GPU with at least 24 GB of VRAM
(the base model is a 9B model taking 18.3 GiB in bf16), and MATLAB R2023a with
the Statistics and Machine Learning Toolbox for the criterion check and the
figures.

```bash
cd exp
pip install -r requirements.txt
export SIA_MODEL_DIR=/path/to/Qwen3.5-9B/master

G3_12_PROFILE=multiunk python g3_12_abstain_method.py   # main experiment
python mk_surf_inputs_syn.py
matlab -batch "run('surf_cv.m')"
matlab -batch "run('make_figs.m')"
```

## What is not here

A companion paper reports a second construction, built from real entities with
a knowledge boundary measured by the model's own sampling self-consistency.
That construction **fails this same criterion**: its attribute names carry the
label, so a discriminator seeing only the attribute name separates the two
classes at 0.817 against a 0.510 baseline. The companion also reports that
construction's item-level cost, a taxonomy of eleven measurement failures, and
a boundary condition for group-normalised RL. It is not part of this paper, and
section 6 explains why the paper reports the criterion's success here but not
the second construction's failure.
